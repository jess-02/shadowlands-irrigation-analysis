# Shadowlands Wholesale Nursery – Irrigation Water Consumption Analysis

## Project Overview

This project focuses on analysing irrigation water consumption at Shadowlands Wholesale Nursery using Microsoft Excel. The aim was to understand water usage across different irrigation blocks, identify consumption patterns, and provide insights that can support better water management and irrigation planning.

The project involved organising raw irrigation data, performing calculations, analysing water consumption and developing an interactive Excel dashboard to communicate the findings.

## Objectives

- Analyse daily irrigation water consumption.
- Compare water usage across different irrigation blocks.
- Examine irrigation runtime and its relationship with water consumption.
- Identify consumption patterns and variations.
- Develop an Excel dashboard to present key findings in a clear and accessible format.

## Tools and Technologies

- Microsoft Excel
- Excel formulas and functions
- Pivot Tables
- Data cleaning and preparation
- Data analysis and visualisation
- Dashboard development

## Project Process

1. **Data Collection:** Gathered irrigation water meter readings and recorded irrigation runtime across different nursery blocks.
2. **Data Preparation:** Organised and structured the collected data for analysis.
3. **Data Analysis:** Calculated water consumption and analysed usage across the different irrigation sections.
4. **Data Visualisation:** Used Excel charts and visual elements to communicate water consumption patterns.
5. **Dashboard Development:** Created an interactive dashboard to summarise the analysis and make the information easier to interpret.

## Key Findings

The analysis provided insights into:

- Water consumption differences across irrigation blocks.
- Variations in daily water usage.
- Irrigation runtime across different sections.
- Areas where water consumption could be monitored more closely.

## Project Deliverable

The final deliverable is an Excel dashboard that provides a visual overview of irrigation water consumption and runtime across the nursery.

## Conclusion

This project demonstrated how data analytics can be applied to practical water management challenges within the horticultural industry. By transforming raw irrigation records into meaningful information, the analysis provides a foundation for improved monitoring, informed decision-making and more efficient water resource management.
